# Asset attribution

The supplied GLB files include Sketchfab metadata identifying their original authors and CC BY 4.0 licensing.

- **Naruto Free Fire** — author metadata: `rocklee.ff123`; license metadata: CC BY 4.0; source metadata is embedded in the GLB.
- **FREE FIRE CLOCKTOWER 3D MODEL BY FFXN** — author metadata: `FFXN`; license metadata: CC BY 4.0; source metadata is embedded in the GLB.

The Naruto output GLB keeps the original mesh, textures, UVs, skin, joints and skeleton. Only the archived `KHR_materials_pbrSpecularGlossiness` material definition was converted to standard metallic-roughness PBR fields for compatibility with current Three.js loaders.
