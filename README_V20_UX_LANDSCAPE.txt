ZUSMO FF V20 - LANDSCAPE UX/UI UPDATE

Fokus update ini hanya UX/UI dan kejelasan alur permainan.

PERUBAHAN UTAMA
- Menu utama dibuat dua area: aksi utama dan alur 3 langkah.
- Tombol MAIN SEKARANG menjadi CTA paling jelas.
- Pemilihan karakter/peta memiliki header langkah, area scroll terpisah, dan dock pilihan tetap di bawah.
- Tombol MULAI PERMAINAN selalu terlihat dan otomatis nonaktif bila pilihan belum tersedia.
- Old Rampage yang file GLB-nya belum ada ditandai BELUM TERPASANG dan tidak dapat dipilih.
- Rouk ditandai sebagai model statis tanpa animasi tulang agar tidak membingungkan.
- Pengaturan utama dibuat seperti hub sederhana.
- Panel ATUR landscape memakai kategori di kiri, kontrol di tengah, preview karakter di kanan.
- Scroll tuning dan daftar kartu memakai native vertical pan.
- Target sentuh diperbesar dan feedback tombol diperjelas.
- HUD diperjelas serta ditambahkan PANDUAN.
- Saat pertama masuk permainan muncul panduan analog, kamera, aksi, dan ATUR.
- Layout diprioritaskan khusus landscape, termasuk landscape dengan tinggi layar kecil.

GAMEPLAY
- Tidak mengubah default movement/animation V18/V19.
- Tidak mengubah kamera bebas dan analog 360 derajat.
- Tidak mengubah asset Naruto / Clock Tower / Rouk.
